# Security Policy

Please report suspected security or safety-impacting defects privately to the maintainer before
opening a public issue. Include the affected commit, build configuration, target toolchain, and a
minimal reproduction when possible.

The project does not claim durability, crash recovery, transactions, exactly-once delivery, or
general thread safety. Reports that depend on those guarantees should be framed as documentation
or contract issues unless a concrete memory-safety or data-corruption defect is shown.
